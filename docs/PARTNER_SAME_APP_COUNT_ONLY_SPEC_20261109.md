# NICO FACTORY 協力店アプリ 正式UI・機能同一仕様（2026-11-09確定）

## 最優先・変更禁止の要求
- 協力店アプリは **自社アプリの画面構成・操作感・機能を丸ごと再利用する**。簡易版・別デザイン・ランキングだけの別画面は不可。
- 自社・協力店の両方の件数を共通正本から参照・集計し、会社別・班別・個人別・商材別ランキングを同じ件数基準で表示する。売上順での順位付けは不可。
- 自社の既存ダッシュボード（実績入力と訂正、分析、個人/商材/班ランキング、班詳細、グラフ、報告文、班・メンバー管理、月間チャンピオン、表示列数の切替、日付/期間切替）を協力店でも同等に利用できるようにする。既存の自社機能は削除しない。
- 協力店の班詳細は **会社→班→担当者→商材→件数**。自社1〜4班と同じカードUI・階層・操作性を使う。
- 協力店の全画面・API・Firestore権限から、売上、単価、利益、原価、キャッシュバック金額と自社の財務原票を完全遮断する。単なるCSS非表示だけでは不可。既存のCB別件数入力の移行は件数・履歴を保持して安全に設計すること。
- 自社Ownerは自分の認証のまま承認済み全協力店の件数を閲覧・訂正可能にする。代理ログイン・所属変更は禁止。協力店オーナーは自社の班・メンバーを管理できる。
- 商材公開ON/OFFは自社Owner限定・サーバー強制。ON商材のみ協力店で入力でき合同商材ランキングへ反映。OFF後も既存の件数と監査履歴は保持。旧9区分は承認済みIDマッピングのみを使い、光/Airの既存区分は当面変更しない。
- 同順位は同件数・同順位。未報告と0件は区別し、照合不能時は未確認として表示する。
- Firestoreの既存売上・単価・CB・件数・訂正・履歴・ユーザー情報は絶対に削除・初期化・自動書換えしない。読み取り検証、バックアップ復元検証、実アカウントでの金額遮断、統合テスト後に段階的本番公開。
- スマホ優先、無料運用を目指し既存Firebase・HTML・Functionsを再利用する。

## 実装順（8工程をまとめて進める）
1. 旧区分を含む商材公開制御と保存権限
2. 商材マッピングと協力店入力画面の公開状態連動
3. 自社・協力店の件数正本・集計統合
4. 合同ランキング（個人・班・商材・会社、日別/月別、同率順位）
5. Ownerの協力店一括管理・監査付き訂正
6. 自社ダッシュボードの全機能を協力店に共通UIとして適用
7. 財務原票遮断・権限・復元・スマホ・回帰テスト
8. 段階的本番公開と公開後確認

## 現在の注意点
- PR #624はDraft、mainと本番への配備は別。コード作成は本番完成を意味しない。
- `index.html` の `partnerSameAppNavigation` は独立した協力店用メニューであり、**自社の全機能と一致していない**。自社のDOM・UIコンポーネントを安全に再利用する方式に寄せる。
- `functions-partner-workspace/service.cjs` の共有ランキングは件数専用。APIとFireStore Rulesの実アカウント検証を完了するまで完全遮断を主張しない。
- NUROのCB別入力は既存件数・履歴との整合性が必要。単純に削除すると入力・訂正が壊れるため、金額を表示しない件数専用の入力方法を別途実装・テストする。
