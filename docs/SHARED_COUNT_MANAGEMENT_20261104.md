# 自社アプリでの協力店合同件数管理（開発版）

## 目的と実装
自社の班別詳細で協力店の会社・当時班・メンバー別商材件数を確認し、同一の共有件数で個人・商材ランキングを比較する。
PR #351 の追加商材・日別/月間合同順位の開発版（5f73aab）に、PR #360 の共通画面配置を統合。追加商材入力を維持し、班/現場欄の重複IDを除去。
班別詳細を開く・日付変更・更新の操作から、会社別照合に続けて合同班・メンバー詳細を取得。合同詳細は初期展開。古い日付の表示を即時消去し、前の要求やサインアウト後の要求を破棄する。
自社の従来金額ランキングへ戻る操作を維持。協力店には件数専用の表示とAPIを使用。月間は引き続き暫定順位であり、未照合を0件にしない。

## 検証
合同集計・公開商材の金額除去・同率順位・当時班・追加商材・保存照合・自社金額維持の既存テストに、新たな開閉/日付競合/ログアウト/入力IDの4テストを追加。
旧テストの保存関数の範囲を現仕様へ更新。原票編集テストは本物の件数整合関数を含め、正常fixtureに正しい保存総件数を指定。サーバーでの公開商品読取は許容するが、協力店への返却はID/名前/順序に限定する既存動作を検証。ブラウザの金額原票読取禁止は維持。
