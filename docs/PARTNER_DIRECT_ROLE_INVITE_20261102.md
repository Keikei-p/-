# 協力店の直接ロール招待 — 2026-11-02

## 実装（未公開）

基点 main: `fc7c0ad0a1175da6bcc3b85ea761e2d310913ec9`。
既存 index の招待画面で所属区分「協力店」、登録済みの会社・班、リーダー/メンバー、メールを選び、既存 `hubCreateInvite` で直接招待する。リンクは同じ `/` のログイン・承諾画面へ戻る。今回の画面は会社代表者登録APIを呼ばない。

協力店リーダーは所属する協力店内の班作成、班員追加、班変更、リーダー/メンバー招待、件数管理を行う。会社範囲はサーバーで最新の users/members/company/relation を検証し、他社・停止・未承認・一般メンバーは管理を拒否する。招待承諾時にも発行者の現在の権限をトランザクション内で再確認する。

登録済み会社が0社でも、同じ招待画面で「新しい協力店を追加」と会社名を指定できる。自社オーナーの明示操作で、新規の件数共有会社・関係・初期1班・招待を一つのトランザクションで作る。代表者アカウントや別登録画面は作らない。既存会社の承認変更・既存データの書換はしない。同じ会社名の再送は二重会社を作らず拒否し、登録済み一覧から再発行する。権限降格・不正入力時は新規文書も作らない。

旧リンクの受入互換は維持する。既存メールの自社所属は二次所属として保存し、移籍しない。過去の実績・当時の班・単価・売上・LINE処理は変更しない。既存協力店 owner を削除/降格せず、新たな代表者ロールも作らない。
