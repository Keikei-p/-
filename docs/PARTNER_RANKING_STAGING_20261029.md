# 協力店の共通商材・合同ランキング｜安全な第1段階（2026-10-29）

**今回mainへ入れる対象は純粋なデータ変換だけ。** `partner/canonical-ranking-groups.mjs` とその架空データテストを取り込む。協力店の別会社招待・承認・商材管理の画面、Firebase Callable、Security Rules、Firestoreの登録・更新、過去履歴の読み書き、Hosting/Workers/LINEの公開・送信は対象外。

- 自社の共有商材は元の商材IDを `shared:<hubCompanyId>:<productId>` として紐付ける。表示名による推測で異なる商材を合算しない。
- 協力店独自商材は `custom:<companyId>:<productId>` で区分。非公開の商品は会社を跨ぐランキングに含めない。
- 自社・相手の会社識別子、件数共有・商材共有の**サーバーで確認した承認**がない限り生成しない。
- 協力店の件数と社内の売上原票は別のデータセットで管理し、計算済み順位を出しても一般利用者には順位・名前以外の金額・件数を出さない（ランキング表示経路は後日実装）。
- **この部品は信頼できるサーバーで検証済みの公開商品リストを受け取る前提**。生の `products` を協力店ブラウザに配るのは禁止。
- 使用時に既存実績・CB・当時単価・商材名を推測で書換しない。会社間で同名商品があっても勝手に同一視しない。
