# 本社Ownerの協力店ディレクトリ100社超対応 — 2026-11-07 STAGING ONLY

## 目的
本社の協力店管理で、既存の100社までの`functions-partner-workspace/service.cjs`の全件取得に依存せず、**25社ずつ**会社名と件数共有承認だけを安全に取得できる独立した候補APIを作る。

## 実装
- `staging/partner-owner-directory-125/directory.cjs`：信頼済みサーバーが認証した自社Ownerのみ。リクエストで会社やUIDを指定できない。ハブ会社IDは本人の最新権限から導く。
- `partnerRelations`をhubCompanyId・document ID順で1ページ26件（表示25＋次ページ有無1件）、25社分の`companies`を読み取り。**売上・商材・単価・CB・実績・ユーザーメールは読み取らない**。無効な会社の承認状態を勝手に有効にしない。
- 戻り値は会社ID、公開可能な会社名、active、countSharingApproved、cursorだけ。個別会社のスタッフ/件数履歴に一切触れず、元の件数入力・招待機能を上書きしない。会社名に金額が含まれれば失敗停止。
- 123社/150社の架空データで5/6ページ読取、別ハブ排除、重複防止、不一致拒否、全本番書込ゼロの検証。
- 前段の125社までのランキング候補 #470 と切り分け。125社以上の存在があっても、一覧はページで見られるが**全社順位の完成を主張しない**。
