# 自社・協力店「常時合算」ランキング仕様 / 残作業（2026-10-29）

## 確定した表示仕様
すべての**件数ランキング・目標件数・日々の報告・商材別件数**を、オーナーが双方承認済みの自社＋協力店で合算する。集計元に会社が複数あっても件数が漏れない。表示には「合同」「自社」「協力店」の切替を追加できるが、**初期値は合同**とする。件数の非表示を希望する個人ランキングだけは**氏名（または公開を承認したニックネーム）＋順位のみ**で金額/件数/目標数を表示しない。

- 総合（班・店舗）ランキング: 合同件数順、班ごとの件数と目標を表示
- 班の件数進捗率ランキング: 実績/目標を別軸に表示。目標不明/0件は順位に無理に混ぜず「目標未設定」
- 商材別ランキング: NURO・電気・MNPなどの**オーナーが承認した商材グループID**で、会社を跨ぐ製品IDを合算。IDが未対応なら総件数には加えるが、勝手に同一商材とみなさず「未統合」と表示し管理者に要対応
- 商材内の個人順位: **順位のみ**（個別件数非表示）
- 金額情報: 売上、単価、CB、利益、金額を用いる順位計算/元データを協力店へ公開しない
- 1位はライオン/王冠/光る演出。2・3位は別演出、同率1位は両者優勝、0件のみなら優勝表示なし。スマホではCSS transform/opacity中心、視差を抑え、prefers-reduced-motionに対応
- 会社・班のチーム名と個人表示名は会社側の公開合意と安全なラベルマスキングを必須とする。

## 今回追加した安全な集計ライブラリ

\`ranking/combined-count-leaderboard.mjs\` を追加し、**財務原票の代わりに**、別途開発した \`publicRecords\` / \`publicRecordLines\` / \`publicProducts\` の金額なしスキーマだけを入力に取る。

- 会社ごとに明示的な相互合意・完全取得済みフラグ・対象月・同一の \`readTime\` を要求。1つでも未承認/未取得/不整合なら**ランキングの一部を表示せず失敗**
- 保存済み \`totalCount\` と商材別 \`count\` を**レコードごとに一致確認**。重複/欠落/別会社/別班/他月/怪しいID・金額文字列を拒否
- 契約件数は必ず全商材へ算入。現在の班情報ではなく**保存時の班ID**へ計上し、班が消えていても元のスナップショットを過去所属として表示する
- 同一UIDでも会社が違えば勝手に同一人として統合しない。個人ランキングの計算には件数を使うが**レスポンスへ個人件数は載せない**
- 2,000件超の実績も前処理に欠けたページが無ければ合算する。目標無しを0件と偽らない。
