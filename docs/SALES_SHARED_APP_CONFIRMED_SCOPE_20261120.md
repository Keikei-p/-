## 1. 完成済み自社アプリをそのまま共有する

- **今の自社ダッシュボードは完成品**。カード、グラフ、ランキング、班詳細、実績入力の配置と操作、日/週/月切替、売上・単価・CB計算、既存の自社機能は原則変更しない。
- **アプリは1つ、実績入力の場所も同じ**。自社と協力店で別の入力アプリ・別ダッシュボードを新規設計しない。既存の `index.html` 内の入力と表示部品を権限に応じて共用する。旧協力店ルートは互換性維持のため残してよいが、新しい主導線として分離を増やさない。
- 自社Owner/正規自社メンバーは従来の正当な権限で売上、単価、CB、金額分析を**今までどおり使える**。協力店対策のために自社の金融表示や保存・計算を削除/停止しない。
- 協力店は同じ位置・同じデザイン・同じ操作で**件数のみ**登録し、件数系のダッシュボード、ランキング、班詳細、日別、履歴を利用する。任意タブの公開はOwnerが全協力店へ一括制御し、未公開はサーバーで拒否する。

## 2. 協力店の売上・単価は絶対に見せない

- 協力店アカウントには売上、単価、CB、収益グラフ、金額原票、価格マスターを**一切表示しない・APIで返さない・Firestoreで読ませない**。
- UI非表示だけでは不合格。サーバーが `users/{uid}`、`companies`、`members`、協力店所属コンテキストとログイン資格を検証する。ブラウザーから渡されるrole/会社ID/タブ公開フラグだけでは許可しない。
- メール、会社コード、二重所属、旧自社権限経由、直接GET/LIST、Function応答、ログアウト後キャッシュ/画面切替のすべてを検証する。漏洩の可能性が残れば公開を停止する。
- 協力店は既存の件数保存用Callable経路を再利用し、**金額原票のFirestore直接書込みは行わない**。既存金融コレクションの権限を拡大しない。
- 自社の売上・単価・CBの正当な閲覧と既存計算は維持する（協力店対策の全社一律OFFは禁止）。

## 3. 協力店の過去実績を完全に引き継ぐ

- 既存 `partnerWorkEntries`、`partnerWorkCountDays`、`partnerWorkAudits`、`partnerWorkTeams`、`partnerWorkStaff`、`partnerPrivateProducts` 等の**原票、件数、獲得日、商材、会社、班、担当者、報告済/未報告、監査・訂正履歴をそのまま保持**する。
- 既存の `counts` と `privateCounts` を読み取り専用で共通件数集計へ投影する。移行・再投入・リセット・二重計上を行わない。既存 `totalCount` と `privateTotalCount` は勝手に加算/上書きしない。
- 既存自社商材名への**一意な完全一致**が取れるものだけ対応付ける。未一致の独自商材を削除しない。従来の光/AIR合算ルールはユーザー指示なしに変更しない。
- 新しい共通入力で登録した件数と過去の保存件数が、同じ会社/班/個人/商材/日付の集計と合同ランキングに重複なく反映される。
- Ownerは協力店件数を訂正でき、訂正前後と操作者の監査履歴は残す。

## 4. Ownerの閲覧と管理の場所

- 既存自社ダッシュボードのレイアウトを変えず、**班詳細**で会社・班・個人別に協力店件数を確認する。
- **協力店詳細**では各会社の全体件数、班、個人、商材、日/週/月、報告状況、入力・訂正履歴を、既存の「売上詳細」に似たUIで件数中心に表示する。別アプリを作らない。
- ランキングは既存の配置と操作を活かし、自社/協力店/合同の件数を集計する。未報告を0件として誤計上せず、同数同順位。協力店の金額項目は一切混在させない。
- Ownerの全社一括商材ON/OFF、公開8タブ（商材ランキング、班ランキング、個人ランキング、班詳細、報告文、日別、登録履歴、目標日割り）は既存の合意どおり維持する。OFFでも過去原票は保存し、過去件数を削除しない。

## 5. 本番化時の変更禁止と完了判定

- **禁止**：実績や原票の再保存/移行/初期化、売上・単価計算変更、既存自社UIの再設計、ログイン方式の無断変更、既存機能削除、強制本番Rules上書き、根拠ないランキング0件補完。
- 本番公開前に実アカウントで自社ログインと金額表示維持、協力店ログイン・件数保存/訂正、金額GET/LIST/API拒否、二重所属、既存件数全件・履歴一致、バックアップ隔離復元、費用上限、スマホを検証する。
- 実際に完了した「実装修正」「CI/Emulator PASS」「本番反映」「公開後確認」を分けて報告。**CI成功のみを本番完成と言わない**。
- このファイルが後続の実装・テスト・レビュー時の仕様照合点。ユーザーによる新指示以外で別画面設計に戻さない。
