# 営業実績管理アプリ

個人営業の月間実績・収益・目標達成率を管理するWebアプリです。

## 現在の機能

- 商材を自由に追加
- 月間目標を設定
- 1件あたりの収益を設定
- 日付・商材・獲得数を入力
- 獲得数を自動集計
- 収益を自動計算
- 目標達成率を自動計算
- 残り目標を自動計算
- ブラウザのlocalStorageにデータを保存
- スマホ表示に対応
